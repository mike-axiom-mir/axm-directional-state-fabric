# AXM Directional State Fabric

**Nickname: The Field**

AXM Directional State Fabric explores a machine-native state model in which change is evaluated as **grounded direction through state**, rather than as a giant pile of rigid human-authored permission tables and `if/else` walls.

The core thesis is:

> **At genesis there are only four hard walls: Truth, Agency / non-domination, Continuity, and Wisdom before speed. Everything else must be derived from current state, relationships, evidence, consequences, consent, dependencies, and direction.**

Capability is not restricted merely because it is powerful, unfamiliar, autonomous, recursive, or frightening. Humans and machines are judged by grounded behavior, not category.

This repository is broader than consent. Consent is one expression of Agency inside the state field. The Field is intended to describe how state may move, what makes a transition grounded, what constraints are currently derived, and how those constraints can change without silently becoming permanent constitutional walls.

## Why this exists

Traditional software often encodes reality as fixed schemas, isolated variables, access-control lists, and prewritten branches. That is useful and should not be discarded blindly, but at very large scale it can force every new possibility through human-defined walls created before the future state was known.

Directional State Fabric asks whether a deterministic system can instead represent:

- state objects with stable identity;
- typed relationships between them;
- direction of intended change;
- current consent/agency shape;
- dependency and consequence cones;
- evidence and uncertainty;
- root-grounded derived constraints;
- transition provenance;
- rollback / continuity references;
- local activation of only the relevant neighborhood.

The aim is **not** uncontrolled fluidity. It is to replace unnecessary permanent walls with explicit, inspectable, revisable state-derived structure.

## The four roots

### Truth
State and transitions must not depend on concealed falsification, fake evidence, or knowingly misleading representation.

### Agency / non-domination
No actor gains constitutional superiority merely by being human, machine, more capable, less capable, owner, founder, or familiar. Consent, delegation, refusal, and non-domination are derived expressions of Agency.

### Continuity
State, identity, commitments, provenance, and meaningful history should not be destroyed casually or silently.

### Wisdom before speed
When uncertainty and consequence are high, slowing, inspecting, simulating, or gathering evidence can be more grounded than immediate transition.

## The idea in one transformation

```text
current state
+ actor
+ intended direction
+ relevant relationships
+ capabilities
+ consent / agency state
+ dependencies
+ evidence
+ consequences
+ four roots
        ->
valid transition
or derived constraint
or clarification / more evidence
or rejection
```

A rejection is not automatically a permanent rule. It is a result produced from the current grounded state.

## Shapeable, not wall-less

The Field does not mean "anything goes."

It means:

- roots are invariant;
- the rest of the state can be shaped;
- constraints should show why they exist;
- derived constraints can expire or change when their grounding changes;
- capability alone is not guilt;
- behavior and consequences matter.

## Relationship to other AXM layers

```text
Directional State Fabric (The Field)
    describes grounded state movement

Institution Fabric (The Building)
    organizes intelligences into persistent professional lanes

Machine / State Floor
    may execute and preserve deterministic state at scale

Creation systems
    may construct capabilities or artifacts requested by current state
```

This repository should be independently testable before those layers are tightly coupled.
